# map.komi.world — фольклорная карта Республики Коми

Интерактивная карта преданий, божеств, праздников и промыслов Коми.
Часть экосистемы [komi.world](https://komi.world) — раздел «Мифология» на главном
сайте ведёт сюда.

## Что это

Карта районов республики, где каждый район кликабелен и открывает свои сюжеты.
Записи привязаны к той земле, где предание записано: Кӧрт Айка — к Корткеросу,
Йиркап — к Синдорскому озеру, Пера — к Прилузью. Сюжеты, бытующие повсеместно
(Ен и Омӧль, Йома), вынесены в отдельный блок под картой.

## Стек

Next.js 16 (App Router, Turbopack, React Compiler), React 19, CSS-модули.
Без внешних зависимостей кроме самого Next — карта строится из `/komi-map.svg`
разметкой путей по id.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

В этом репозитории дев-сервер поднимается на :8936 через `komi-map` в
`KOMI/.claude/launch.json`.

Репозиторий: [github.com/sassnemu1/komi-map](https://github.com/sassnemu1/komi-map).
Проект Vercel `komi-map` привязан к нему — пуш в `main` деплоит продакшен.
Живой адрес сейчас: **[komi-map.vercel.app](https://komi-map.vercel.app)**.

Configuration*: зона `komi.world` не на Vercel. Нужна одна запись у регистратора
komi.world:

| Тип | Имя | Значение |
|---|---|---|
| CNAME | `map` | `89e506f67907d454.vercel-dns-017.com.` |

После её появления Vercel сам выпустит сертификат и адрес заработает. Кнопка
«Открыть карту преданий →» в секции «Мифология» на komi.world уже указывает на
`https://map.komi.world` (переопределяется через `NEXT_PUBLIC_MAP_URL`).

## Структура

```
src/
  app/                     layout + главная страница
  components/
    FolkloreMap/           SVG-карта: hover, выбор, фильтр, клавиатура
    EntryPanel/            боковая панель: список сюжетов и текст записи
    MapExplorer/           состояние: выбранный район, жанр, открытая запись
  data/
    districts.js           19 районов ⇄ id путей в komi-map.svg
    folklore.js            корпус сюжетов
public/
  komi-map.svg             карта районов
  flags/                   реальные флаги 8 муниципалитетов
```

`districts.js` — копия `komiDistricts.js` с komi.world. При изменении править в
обоих местах.

## Модель данных

Запись в `folklore.js`:

```js
{
  id, title, komi, genre,
  districts: ["path3119"],   // id путей; [] + areaWide: true — без привязки
  place, period, lead,
  body: ["абзац", "абзац"],
  sources: [...],
  verified: "strong" | "review",
}
```

Разделы: эпос и предания, божества и духи, народные праздники, обряды и верования,
промыслы и ремёсла.

## Статус привязок

`verified: "strong"` — район назван в самом сюжете (топоним, река, село).
`verified: "review"` — сюжет документирован, но привязка или трактовка требует
сверки с первоисточником.

Сверка (по «Мифологии коми» ред. Конакова, cultmap.ru, Жакову, Лимерову,
Рочеву и историческим источникам) закрыла все 7 старых review-записей — все
семь переведены в `areaWide`, точечные привязки не подтвердились:

| Запись | Итог сверки |
|---|---|
| Войпель | areaWide, остаётся `review`: Послание Симона (1501) — о Перми Великой; внутри РК только вторичные привязки (Гам, Тельпос-из) |
| Вӧрса | areaWide, **strong**: повсеместное бытование документировано |
| Васа | areaWide, **strong**: повсеместное бытование документировано |
| Йома | areaWide, `review`: локализации в фольклоре нет; «резиденция» в Бызовой — брендинг 2021 г. |
| Зарни Ань | areaWide, `review`: источники XVI в. помещают идол за Уралом; имя — калька XIX в. |
| Пелысь | areaWide, `review`: рябина — оберег (документировано), «орнаментальный мотив» убран из текста |
| Чудь белоглазая | areaWide, **strong**, жанр сменён на `epos`: по классификации Ю. Г. Рочева сюжет бытует по всей старой коми территории; Усть-Цильма в источниках не фигурирует вовсе |

Записи со статусом `review` показывают сноску в тексте сюжета на сайте.

### Раунд 2: районы, опустевшие после перевода духов в areaWide

Для четырёх из пяти пустых районов найдены документированные сюжеты. Каждый
черновик отдельно проверялся на опровержение: агент-скептик открывал
первоисточники и пытался сломать запись. Все четыре пережили сверку с высокой
уверенностью, но ни один не прошёл её без правок — исправления внесены в текст.

| Район | Запись | Что исправила сверка |
|---|---|---|
| Воркута | **Хальмеръю: река покойников** (`obryad`, strong) | Посёлок возник до шахты, а не из-за неё (разведка 1943, посёлок 1954, шахта 1957); ликвидация — постановление 1993, расселение до 1995, упразднение 1996 |
| Вуктыл | **Тельпос-из и бог Шуа** (`duhi`, strong) | Сверено по полному тексту Сорокина («Этнографические этюды», 1999); уточнены датировки записей и отношение Шуа к Войпелю (тождество не доказано) |
| Усть-Куломский + Корткеросский | **Бурсьылысьяс** (`obryad`, strong) | Ермолину ошибочно приписан перевод Псалтыри; «расхождение источников» о дате рождения было сконструировано; запрет Синода и хронология 1920-х исправлены |
| Койгородский | **Николин день в Кажыме** (`prazdnik`, strong) | Костромская губерния в источниках не фигурирует — заводских крестьян везли из Вологодской, Вятской и Великоустюжской провинций |

### Раунд 3: Сыктывдинский и сверка чуди

По Сыктывдинскому району работали два агента с непересекающимися заданиями —
один по преданиям о местах, другой по обрядам и промыслам. Оба нашли
документированные сюжеты, оба пережили сверку.

| Район | Запись | Что исправила сверка |
|---|---|---|
| Сыктывдинский | **Иван лун и Петыр лун** (`prazdnik`, strong) | Причина обета в источнике дана двумя несовместимыми версиями (падёж скота / пожар) — обе оставлены как версии, гипотеза об иконе не внесена |
| Сыктывдинский | **Выльгортские горшечники** (`remeslo`, strong) | Три чужие атрибуции: перечень центров и описание домашнего гончарства принадлежат В. Н. Белицер, рыночные данные — Г. Н. Романовой, а не Чудовой; лид выворачивал вывод источника (переход к ремеслу был переходом в руки мужчин) |

Сверка чуди перевела запись в `areaWide` и сменила жанр на `epos`. Побочный
эффект: Удорский район остался без записей — чудь была его единственной
привязкой, а сверка показала, что Удора (Вашка) лишь одна из зон бытования,
а не адрес предания.

### Раунд 4: Удора и критик полноты

По Удорскому району работали три агента с непересекающимися заданиями —
предания, обряды, ремёсла. Все трое нашли документированные сюжеты, все трое
пережили сверку.

| Запись | Жанр | На чём стоит |
|---|---|---|
| **Глöт — зверь из мезенского омута** | `epos` | Текст № 72 в «Коми легендах и преданиях» (Рочев, 1984), записан в 1964 г. в Глотове от В. А. Коновалова, 84 лет; проверяющий скачал PDF и сверил паспорт и пагинацию |
| **Девятая пятница в Кривом — купание икон** | `prazdnik` | Лимеров (Рябининские чтения — 2007), Власова (Известия Коми НЦ, 2014), карточка объекта ОНКН |
| **Удорская роспись по дереву: козяль с Вашки** | `remeslo` | Объект ОНКН № 2971, полевые работы Шарапова и Земцовой 2016–2018 гг. по Вашке, Выми и Вычегде |

С этими тремя записями **все 19 районов покрыты**.

Отдельный агент-критик прошёл по всему корпусу и выдал 39 замечаний
(20 высокой важности). Два внутренних противоречия исправлены сразу:

- у `voypel` лид называл Войпеля «единственным» божеством в летописи, а body
  строкой ниже — «одним из двух»; лид переписан;
- `voypel` утверждал тождество Шуа и Войпеля, которое сверенная запись
  `telpos-iz-shua` со ссылкой на Лимерова объявляет недоказанным; третий абзац
  приведён в соответствие, Лимеров добавлен в источники.

Там же нашлась ошибка отображения: сноска «Привязка сюжета к району требует
сверки» показывалась и на `areaWide`-записях, у которых привязки к району нет
вообще. Теперь для них текст другой — о трактовке, а не о привязке.

Главное системное замечание критика — одиннадцать старых записей стояли на
источниках-заглушках того же типа, что уже вычищались у чуди («Коми народный
эпос», «Предания о тунах», «Печорские записи»), и у девятнадцати записей абзацы
были в четыре-шесть раз короче нормы.

### Раунды 5–6: замена заглушек на реальную библиографию

Четырнадцать записей переписаны заново по первоисточникам. Проверяющим прямо
указали на риск ИМЕННО ЭТОГО раунда: требование абзацев в 500–900 знаков
провоцирует выдумывать подробности, чтобы добрать объём. Каждый сверял «было» и
«стало» и спрашивал, откуда взялись новые полтысячи знаков.

Результат: 13 записей подтверждены, **1 отклонена**.

Теперь каждая строка источника говорит, читан ли он de visu или взят из чужого
пересказа («цит. по: …»). Корпус перестал делать вид, что держал в руках то,
чего не держал.

Что сверка изменила по существу:

| Запись | Что выяснилось |
|---|---|
| `pera` | Самая ранняя запись сделана Лепёхиным на **верхней Каме**, а не на Лузе. Прилузская привязка держится на озере, которое источник называет двояко, и на скульптуре 2012 года, которую тот же источник зовёт турбрендом района. `strong` → `review` |
| `yag-mort` | Сюжет известен прежде всего по печатному тексту М. Ф. Истомина 1848 года; выходные данные первопубликации расходятся (Архангельские или Вологодские ведомости). Плесовский звал текст «обычной волшебной сказкой», наполненной первым публикатором деталями «местного сказания» |
| `shypicha` | **Привязка к Вотче и Сысольскому району не подтвердилась ничем.** Все источники помещают Шыпичу в устье Сысолы — Усть-Сысольск, с. Слобода. Сыктывкара в `komi-map.svg` нет, поэтому запись переехала в Сыктывдинский со статусом `review` |
| `stefan-perm` | Жанр сменён `obryad` → `epos`: это повествовательная проза |
| `pelys` | Запись была сшита из двух тем — рябина-оберег и геометрический орнамент. Орнамент убран, жанр `remeslo` → `obryad` |
| `en-omol` | Связная космогония — реконструкция из разрозненных записей, а не единый записанный миф |

**Отклонённая правка — `zarni-an`.** Проверяющий нашёл в ней сшитую из кусков
летописную цитату, которой нет ни в одном источнике; утверждение, взятое из
Википедии, но подписанное именем Шутовой; приписанное Трубецкому слово
«Сорни-эква», которого у Шутовой нет вообще; неверный постраничный охват у
Миллера и перевранную кавычку из Герберштейна. Правка отброшена целиком,
исходная запись оставлена нетронутой — она по-прежнему стоит на заглушках и
ждёт переделки.

Побочный эффект переезда `shypicha`: Сысольский район остался без записей.

Со статусом `review` осталось пять записей: Старая родина ижемцев, Войпель,
Йома, Зарни Ань, Пелысь. Остальные — `strong`.

Всего: **29 записей**, охвачено **18 из 19** районов, 8 сюжетов — areaWide.
По жанрам: эпос 11, божества и духи 7, обряды 4, праздники 4, ремёсла 3.
Без записей: Сысольский район.
