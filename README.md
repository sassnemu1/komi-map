# map.komi.world — фольклорная карта Республики Коми

Интерактивная карта преданий, божеств, праздников и промыслов Коми.
Часть экосистемы [komi.world](https://komi.world) — раздел «Мифология» на главном
сайте ведёт сюда.

## Что это

Карта районов республики, где каждый район кликабелен и открывает свои сюжеты.
Записи привязаны к той земле, где предание записано: Кӧрт Айка — к Корткеросу,
Йиркап — к Синдорскому озеру, Пера — к Прилузью. Сюжеты, бытующие повсеместно
(Ен и Омӧль, Йома), вынесены в отдельный блок под картой.

## Стек

Next.js 16 (App Router, Turbopack, React Compiler), React 19, CSS-модули.
Без внешних зависимостей кроме самого Next — карта строится из `/komi-map.svg`
разметкой путей по id.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

В этом репозитории дев-сервер поднимается на :8936 через `komi-map` в
`KOMI/.claude/launch.json`.

|---|---|---|

`https://map.komi.world` (переопределяется через `NEXT_PUBLIC_MAP_URL`).

## Структура

```
src/
  app/                     layout + главная страница
  components/
    FolkloreMap/           SVG-карта: hover, выбор, фильтр, клавиатура
    EntryPanel/            боковая панель: список сюжетов и текст записи
    MapExplorer/           состояние: выбранный район, жанр, открытая запись
  data/
    districts.js           19 районов ⇄ id путей в komi-map.svg
    folklore.js            корпус сюжетов
public/
  komi-map.svg             карта районов
  flags/                   реальные флаги 8 муниципалитетов
```

`districts.js` — копия `komiDistricts.js` с komi.world. При изменении править в
обоих местах.

## Модель данных

Запись в `folklore.js`:

```js
{
  id, title, komi, genre,
  districts: ["path3119"],   // id путей; [] + areaWide: true — без привязки
  place, period, lead,
  body: ["абзац", "абзац"],
  sources: [...],
  verified: "strong" | "review",
}
```

Разделы: эпос и предания, божества и духи, народные праздники, обряды и верования,
промыслы и ремёсла.

## Статус привязок

`verified: "strong"` — район назван в самом сюжете (топоним, река, село).
`verified: "review"` — сюжет документирован, но привязка или трактовка требует
сверки с первоисточником.

Сверка 2026-08-24 (по «Мифологии коми» ред. Конакова, cultmap.ru, Жакову,
Лимерову и историческим источникам) закрыла 6 из 7 старых review-записей —
все шесть переведены в `areaWide` (точечные привязки не подтвердились):

| Запись | Итог сверки |
|---|---|
| Войпель | areaWide, остаётся `review`: Послание Симона (1501) — о Перми Великой; внутри РК только вторичные привязки (Гам, Тельпос-из) |
| Вӧрса | areaWide, **strong**: повсеместное бытование документировано |
| Васа | areaWide, **strong**: повсеместное бытование документировано |
| Йома | areaWide, `review`: локализации в фольклоре нет; «резиденция» в Бызовой — брендинг 2021 г. |
| Зарни Ань | areaWide, `review`: источники XVI в. помещают идол за Уралом; имя — калька XIX в. |
| Пелысь | areaWide, `review`: рябина — оберег (документировано), «орнаментальный мотив» убран из текста |
| Чудь белоглазая | НЕ сверена (агент упал на 529) — остаётся `review` с привязкой Удора/Усть-Цильма |

Записи со статусом `review` показывают сноску в тексте сюжета на сайте.

### Раунд 2: районы, опустевшие после перевода духов в areaWide

Для четырёх из пяти пустых районов найдены документированные сюжеты. Каждый
черновик отдельно проверялся на опровержение: агент-скептик открывал
первоисточники и пытался сломать запись. Все четыре пережили сверку с высокой
уверенностью, но ни один не прошёл её без правок — исправления внесены в текст.

| Район | Запись | Что исправила сверка |
|---|---|---|
| Воркута | **Хальмеръю: река покойников** (`obryad`, strong) | Посёлок возник до шахты, а не из-за неё (разведка 1943, посёлок 1954, шахта 1957); ликвидация — постановление 1993, расселение до 1995, упразднение 1996 |
| Вуктыл | **Тельпос-из и бог Шуа** (`duhi`, strong) | Сверено по полному тексту Сорокина («Этнографические этюды», 1999); уточнены датировки записей и отношение Шуа к Войпелю (тождество не доказано) |
| Усть-Куломский + Корткеросский | **Бурсьылысьяс** (`obryad`, strong) | Ермолину ошибочно приписан перевод Псалтыри; «расхождение источников» о дате рождения было сконструировано; запрет Синода и хронология 1920-х исправлены |
| Койгородский | **Николин день в Кажыме** (`prazdnik`, strong) | Костромская губерния в источниках не фигурирует — заводских крестьян везли из Вологодской, Вятской и Великоустюжской провинций |

Сыктывдинский остаётся единственным районом без записи: агент, работавший по
нему, упал на ошибке API.

Сюжеты со статусом `strong`: Пера, Кӧрт Айка, Йиркап, Яг Морт, Шыпича,
Маньпупунёр, Прокудливая берёза, Ен и Омӧль, Вӧрса, Васа, Усть-Цилемская Горка,
Изьватас, Ижмо-колвинский эпос, Эшмесское святилище, Тельпос-из и бог Шуа,
Хальмеръю, Бурсьылысьяс, Николин день в Кажыме.

Всего: **24 записи**, охвачено **18 из 19** районов, 7 сюжетов — areaWide.
